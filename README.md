A deterministic program that writes one line — the elevator pitch a city pigeon gives investors for its startup — to `/output/entry.txt` for make.fun's Pigeon Pitch, One Line bounty.

Why this line: statues, crumbs, and the early bird are all city-pigeon life; the startup register (billboard, subscription, invest now) carries the pitch, and the joke lands on the last clause.

## Run it

```sh
python3 main.py
```
